# Release 0.39.39 — actionable audit rejections and compact cards

## What shipped

Audit rejection notices now hand the work back to the agent instead of dumping a report tail. The field screenshot (`Screenshot_20261019_105241.png`) showed GLLA v0.39.38 printing `Auditor disapproved. Report excerpt:` followed by file timestamps, index paths and command output, with the useful Required-fixes section flattened into the permanent card and a footer mixing a saved workflow with unconfirmed execution. Both the normal completion-rejection path and the provider-retry settlement path now use one bounded ownership handoff: the agent's corrections, the person's action, and a link to the full report.

Compact blocked cards lead with a two-line action and a short reason preview, use a one-line conditional resume, and keep judgment/compaction diagnostics in detailed status. GLLA's shared one-line status segment is capped at 96 cells because other extensions share that bar. Successful pauses render a short receipt pointing at the action card. An unconfirmed saved workflow is presented as work saved rather than working.

This release also carries the two durable-admission repairs from the 2026-10-19 project audit pass: carryover clearing and `resume_goal` now fail closed instead of acknowledging success after a refused state write.
