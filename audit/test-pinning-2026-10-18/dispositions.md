# Inventory dispositions and preserved contracts

The baseline-wide manifest and source discovery are in `inventory.md` (444 standard test files plus nonstandard verification roots). Marker flags are **triage categories**, not a test-value score. Every baseline file was scanned; semantic inspection was concentrated on suspect assertions and useful controls, not claimed exhaustive line-by-line review. For flagged files without an evidenced incidental coupling, disposition is **retain — intent not established by the marker scan**. Unflagged files are not certified pin-free. This explicitly records uncertainty rather than deleting unreviewed tests or asserting that all existing pins are justified.

## Controls

`node scripts/verify-test-pin-controls.mjs` copies only GLLA inputs to a temporary directory, applies changes there, runs focused checks with per-process timeouts, verifies intended failures, restores between cases, and removes copied sources in `finally`. It is standalone, opt-in, never imported by the collected suite, and does not mutate live workflows. Its receipts distinguish expected failing subprocesses from failure of the control harness. Existing affected suites and clean types are separate gates.
